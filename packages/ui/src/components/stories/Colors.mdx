## Usage Guidelines

### Accessibility

- Always ensure sufficient contrast ratios when combining colors
- Use darker shades (700-900) for text on light backgrounds
- Use lighter shades (100-300) for backgrounds and subtle elements

### Semantic Usage

- **Red**: Errors, destructive actions, urgent alerts
- **Orange**: Warnings, caution states
- **Forest**: Success states, positive feedback
- **Sky**: Informational content
- **Grey**: Text, borders, neutral backgrounds

The other colors (Lime, Navy, Purple) can be used to bring variation in case there are many colored elements, but should be used sparingly.

### Implementation

Colors are available as SCSS variables in `src/styles/_colors.scss`:

```scss
// Base colors
$white: #ffffff;
$black: #1f1d21;

// Primary brand
$red: #bd0032;

// Grey scale
$grey-100: #fafafa;
$grey-500: #b1aca9;
$grey-900: #282524;

// Color palettes (100-900 range available for each)
$red-500: #ec1342;
$orange-500: #ffa733;
$lime-500: #efe639;
$forest-500: #41aa56;
$sky-500: #63c9ee;
$navy-500: #3385cc;
$purple-500: #b42d9f;
```
