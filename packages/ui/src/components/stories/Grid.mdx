# Grid System

Layout foundation for all UvA DataNose applications. Based on a 12-column grid with consistent margins and gutters.

## Container

`Container` centers content horizontally and applies the 12px side margins. Use it to constrain content to the design system's maximum width.

```tsx
import { Container } from '@datanose/ui';

// Default — constrained to 944px, centered
<Container>
  <p>Page content</p>
</Container>

// Custom max-width
<Container maxWidth={1200}>
  <p>Wider content</p>
</Container>

// Full-width — no max-width constraint
<Container maxWidth="full">
  <p>Edge-to-edge content</p>
</Container>
```

## Grid & GridItem

`Grid` sets up the 12-column grid with 24px column gutters. `GridItem` controls how many columns a child spans.

```tsx
import { Grid, GridItem } from '@datanose/ui';

<Grid>
  <GridItem span={6}>Left half</GridItem>
  <GridItem span={6}>Right half</GridItem>
</Grid>
```

### Column spans

Any combination of spans that add up to 12 works:

```tsx
// Three equal columns
<Grid>
  <GridItem span={4}>One third</GridItem>
  <GridItem span={4}>One third</GridItem>
  <GridItem span={4}>One third</GridItem>
</Grid>

// Sidebar + content
<Grid>
  <GridItem span={3}>Sidebar (3/12)</GridItem>
  <GridItem span={9}>Content (9/12)</GridItem>
</Grid>

// Full-width item
<Grid>
  <GridItem span={12}>Full width</GridItem>
</Grid>
```

## Combining Container and Grid

The typical pattern is to wrap a `Grid` in a `Container`:

```tsx
import { Container, Grid, GridItem } from '@datanose/ui';

function PageLayout() {
  return (
    <Container>
      <Grid>
        <GridItem span={12} spanMd={3}>
          <Sidebar />
        </GridItem>
        <GridItem span={12} spanMd={9}>
          <MainContent />
        </GridItem>
      </Grid>
    </Container>
  );
}
```

For full-width sections that break out of the container (e.g. a hero banner), apply the `Container` separately per section:

```tsx
{/* Full-bleed hero */}
<HeroBanner />

{/* Constrained body */}
<Container>
  <Grid>
    <GridItem span={12}>
      <ArticleBody />
    </GridItem>
  </Grid>
</Container>
```

## Implementation notes

- The grid is built with CSS Grid (`display: grid`, `grid-template-columns: repeat(12, minmax(0, 1fr))`).
- Gutters use `gap-x` only — vertical spacing is controlled via `rowGap` on `Grid` or margin/padding on `GridItem` children.
- The `Container`'s 12px side margins use Tailwind's `px-3` (3 × 4px = 12px).
- The 24px gutter uses Tailwind's `gap-x-6` (6 × 4px = 24px).
- All classes use the `ui:` prefix to avoid conflicts with consuming app styles.
